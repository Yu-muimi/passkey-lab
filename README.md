# パスキーとセキュリティシアター

パスキー（WebAuthn）の仕組みと、効果の薄い「セキュリティシアター」を、手を動かしながら理解できる解説ページです。

**公開ページ → https://yu-muimi.github.io/passkey-lab/**

## 内容
- パスキーの仕組み（公開鍵・PRF・登録／認証）
- 攻撃の体験（フィッシング・サーバー漏洩のハッシュ&ソルト・総当たり計算機）
- 守れること・守れないこと（回復の弱さ、セッションクッキー窃取、メタデータ）
- セキュリティシアター図鑑／パスワードからパスキーへの60年史

SHA-256 の体験や総当たり計算機など、インタラクティブに触って確かめられます。
